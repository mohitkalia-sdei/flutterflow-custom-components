# FlutterFlow Custom Components & Actions Library 🧩⚡

A curated collection of production-ready **Custom Widgets** and **Custom Actions** written in Dart/Flutter, specifically crafted for seamless integration into **FlutterFlow** projects.

When FlutterFlow's standard visual builder hits limitations, these custom components provide advanced functionality without sacrificing low-code development speed.

---

## 📦 What's Inside

### 1. Custom Widgets (`lib/widgets/`)
* **`GradientCircularProgress`**: High-performance animated circular progress bar with multi-color gradient support and customizable stroke cap.
* **`InteractiveCreditCard`**: Flippable 3D credit card widget with auto-formatting number display and CVV rotation animation.

### 2. Custom Actions (`lib/actions/`)
* **`formatCurrencyAction`**: Converts raw numeric values into localized currency strings with custom symbol and decimal precision.
* **`calculateTimeAgoAction`**: Generates human-readable timestamps (e.g., "5 mins ago", "2 hours ago") for social feeds and activity logs.

---

## 🛠️ How to Use in FlutterFlow

1. In your **FlutterFlow project**, navigate to **Custom Functions & Code** (left toolbar).
2. To add a widget:
   - Click **Add Custom Widget**.
   - Copy the code from `lib/widgets/<widget_name>.dart`.
   - Define matching parameters in the FlutterFlow parameters panel.
3. To add an action:
   - Click **Add Custom Action**.
   - Copy the logic from `lib/actions/<action_name>.dart`.
   - Save and use inside any FlutterFlow Action Flow!
